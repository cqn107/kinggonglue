# 地形作战指南

> 终末地的战斗深度一半来自 3D 箱庭地图——把地形当武器用，而不是当背景板。

## 三大立体作战维度

### 1. 垂直空间机动

地图是立体的，攻击与走位同样立体：

- **抢高点**：狙击手利用崩塌建筑搭建**狙击点**，获得射程与视野优势
- **跨层打击**：立体机动让"绕后"不限于平面——从上方突袭常被忽视
- {{待验证：高低差对命中/伤害的具体加成}}

### 2. 地形破坏

场景物体不是装饰：

- **崩塌建筑**可以制造新的通路、掩体，或直接改变战场结构
- 重装单位可架设**临时防御工事**，把开阔地改造成可守阵地
- 高难作战里"先拆哪块地形"本身就是解法的一部分

## 实战检查清单（开战前 10 秒）

- [ ] 敌人配置：有没有必须优先处理的目标（治疗型/远程型）
- [ ] 地形：哪里可以拆？哪里可以架狙击点/工事？
- [ ] 垂直路线：高点在哪，绕后路线怎么走
- [ ] 天气：当前天气对我的队伍是增益还是减益
- [ ] 失衡计划：谁先手破失衡，失衡后全队谁来打爆发

## 不同场景的应用

| 场景 | 地形策略 |
|---|---|
| 常规推图 | 顺手利用即可，效率优先 |
| 精英战 | 架工事/狙击点，减少承伤面 |
| 高难作战 | 地形是解法核心——先规划再开打 |
| 多波次防守 | 预设防线，利用破坏改变敌人动线 |

## 常见错误

1. **平面对平面**：只用地面走位，浪费整个垂直维度
2. **无视天气**：开打才发现减益
3. **高难硬拼数值**：多数高难机制用地形解法比堆练度便宜得多
4. **破坏随机化**：该留的掩体提前拆了，想用的建筑没规划
