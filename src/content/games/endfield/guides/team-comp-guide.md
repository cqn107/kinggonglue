# 队伍构筑与资源规划

> 服务型游戏的差距不在抽卡，在**资源投放纪律**。本文给开荒到中期都适用的构筑框架，具体角色推荐随版本更新（见 Tier List）。

## 标准 4 人队模板

| 职能 | 职责 | 数量 |
|---|---|---|
| 主 C | 主要输出，技能循环核心 | 1 |
| 破失衡位 | 快速积累失衡值，开爆发窗口 | 1 |
| 治疗 | 续航与容错 | 1 |
| 功能位 | 狙击/工事/控场，补足机制 | 1 |

**构筑核心思路：围绕技力循环与失衡值构建队伍**——失衡窗口是全队输出的放大器，破失衡能力的优先级高于堆面板输出。

## 养成资源投放原则

1. **集中养 4 个，不要养 8 个**——资源摊薄 = 全队都弱
2. 优先级：主 C 等级/技能 → 破失衡位关键技能 → 治疗等级 → 功能位最后

## 体力与活动规划

- **版本活动是资源大头**：每个版本的限时活动奖励远超日常，优先清空
- 日常体力：优先投入主线推进与基建解锁，再回头刷养成材料
- {{待验证：体力恢复机制与溢出规则}}

## 高难作战的准备顺序

1. 主力 4 人队练度达标（等级/技能跟当前版本上限）
2. 至少 1 个高破失衡位成型
3. 理解地形互动：垂直机动、地形破坏、动态天气都是解法的一部分——狙击手利用崩塌建筑架狙击点、重装单位架临时工事
4. 参考 Tier List 选对场景特化角色（活动特化评级会注明）

## 常见错误

1. 平均养成 → 资源枯竭，全队平庸
2. 无视失衡机制硬堆输出 → 高难作战打不动
3. 体力乱花在低回报材料本 → 先看本周活动加倍
4. 忽略基建反哺 → 养成材料全程靠刷（正确姿势：产线自给，见《基建自动化指南》）
