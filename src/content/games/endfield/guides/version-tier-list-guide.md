# 终末地 Tier List 方法论

> 本篇是本站评榜规则的说明 + 当前版本榜单框架。**具体评级随版本更迭，每次版本更新后 48 小时内刷新**。当前数值正在实测校对，请以标注的验证日期为准。

## 为什么需要方法论而不只是榜单

网上强度榜的问题：不看场景（开荒 vs 高难）、不标版本、没人说明评测条件。本站榜单四条规则：

1. **每期标注版本号与验证日期**
2. 评级分场景：开荒期 / 高难作战 分开评
3. 四维打分，不看单一 DPS
4. 评级变化在页顶写清升降原因

## 四维评分标准（各 1–5 分）

| 维度 | 权重 | 说明 |
|---|---|---|
| 输出能力 | 30% | 技能循环伤害、爆发窗口利用率 |
| 破失衡能力 | 25% | 失衡值积累效率——失衡窗口是全队输出放大器，权重高于常规游戏 |
| 生存/辅助 | 20% | 治疗、护盾、工事、控场 |
| 泛用性 | 25% | 地形适应性、队伍兼容度、培养成本 |

评级映射：T0（≥4.5 多场景必练）/ T1（≥4.0）/ T2（≥3.0）/ T3（补强用）。

## 评榜的使用姿势

1. **开荒期看 T2 不亏**：T0/T1 往往吃练度，低练度阶段 T2 的"低配好用"角色性价比更高
2. **高难看破失衡**：4 人队至少 1 个高破失衡位
3. **不要全队照抄**：先定主 C，再围绕技力循环补功能位
4. **警惕"活动特化"评级**：为某活动量身适配的角色会临时上调，会注明
