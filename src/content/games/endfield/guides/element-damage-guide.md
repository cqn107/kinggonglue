# 元素反应与伤害类型指南

> 终末地的配队不是凑齐五个强的——是**围绕一种伤害类型建队**。先懂机制，再看 Tier List。

## 两大伤害体系

| 体系 | 元素 | 加成属性 | 特性 |
|---|---|---|---|
| 法术伤害 | 热 / 冰 / 电 / 自然 | INT | 触发元素反应 |
| 物理伤害 | 无元素 | STR | 叠易伤（Vulnerable），爆发窗口增伤 |

## 法术系：元素反应

- 同系元素攻击连续命中可触发反应，**反应吃的是队伍挂元素频率**
- 典型联动：破防工具人先挂元素 → 核心 DPS 收尾触发反应
- 四种元素的强度随版本波动——结论看当期 Tier List（方法论篇），机制理解是恒定的

## 物理系：易伤叠层

- 物理攻击叠加易伤层数，**配合硬直窗口吃 50% 增伤**（见破防篇）
- 物理队的要求：叠层速度 + 大剑手敲硬直 + 主 C 爆发三件齐
- 主角（管理员）就是物理系——零氪开荒天然走物理队

## 建队决策树

```
你有没有强力 6 星主 C？
├─ 有（热/冰系）→ 围绕该元素组队：挂元素工具人 + 该系副C + 奶
└─ 没有 → 物理队起步：主角主C + 大剑破防 + 挂易伤 + 奶
```

混搭的代价：元素反应触发不了、易伤叠不满、增益加错人——**每个位置都在为同一个伤害类型服务**，这是配队篇所有推荐阵容的底层逻辑。

## 常见误区

1. ❌ 全队堆不同元素"什么都能打"——实际什么都触发不满
2. ❌ 物理队不带大剑——没有硬直窗口，易伤叠了吃不到爆发
3. ❌ 法术队忽略 INT 面板——反应倍率吃属性，不是吃星级
