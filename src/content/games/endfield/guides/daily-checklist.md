# 日常与周常清单

> 服务型游戏的进度 80% 来自每天那 15–30 分钟。按这份动线走，不漏项、不空转。

> 🧰 **配套互动工具**：[每日清单追踪器](/tools/endfield-daily-checklist) —— 每日项按天自动重置、周常按周重置，勾选进度本地保存。

## 每日必做（15–20 分钟）

- [ ] **领挂机收益**：哨站订单结算、基地产出一次性收空
- [ ] **清日常任务**：给抽卡资源的任务链优先
- [ ] **消耗体力**：优先卡进度的突破/技能材料副本
- [ ] **产线体检**（1 分钟）：封装机有没有在"饿肚子"？电力余量够不够？库存有没有爆仓？
- [ ] **派遣队收发**：干员派遣收一次、发一次

## 每周必做

- [ ] **周常任务**全部清空（奖励通常含抽卡券）
- [ ] **高价值限定副本**：周刷次数限制的素材本，次数用满
- [ ] **版本活动**：检查当期活动商店，先换限时商品再换常驻
- [ ] **Tier List 复查**：新干员/新装备是否改变了配队？（见本站 Tier List 方法论篇）

## 体力分配原则

1. **卡进度优先**：推不动主线时，体力全给卡住的材料
2. **不刷溢出**：仓库里超过 2 周用量的材料立刻停手
3. **留余量**：新版本/新干员池前一晚，体力不要清零，留给新角色养成

{{待验证：各阶段体力自然回复上限、副本掉率与材料需求表}}

## 挂机收益检查（睡前 30 秒）

- 产线在转（设备无停机闪烁）
- 哨站订单物资充足（不会半夜断供）
- 仓库未满（爆仓 = 挂机白挂）
