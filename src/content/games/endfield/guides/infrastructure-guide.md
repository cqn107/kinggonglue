# 基建自动化指南

> 终末地的效率差距 90% 在基建。本文给可落地的规划顺序与布局原则，具体数值随版本校对（标 {{待验证}}）。

## 为什么基建是核心

终末地是"前线作战 + 后方生产"双线程：基地的自动化产线决定养成材料的自给速度。手动刷材料的效率比自动化低一个数量级——**开荒期主线的第一目标就是解锁并跑通基建**。

## 第一步：电力网络（一切的前提）

所有产线都吃电力，规划原则：

1. **发电设施先行**：先保证电力冗余 ≥ 20%，再扩产线——避免扩线时全厂停摆
2. **分区供电**：按功能分区（采集区/加工区/仓储区），避免单点故障全图瘫痪

## 第二步：物流运输（自动化的上限）

物流决定自动化上限，三个关键点：

1. **仓库存取线**：库房与产线之间的存取路径是第一瓶颈——优先打通
2. **共享设备**：善用**滑索架、便捷存取站**等互助道具，减少重复铺设
3. **无人机调度**：自动采集与加工靠无人机调度，保持调度半径内有任务

## 第三步：产线闭环（真正解放双手）

让"采集 → 加工 → 仓储"形成闭环：

```
采集设施 → 初级加工 → 高级加工 → 仓储 → （养成消耗）
    ↑            ↑                    |
    └── 物流回流 ←────────────────────┘
```

自检清单：
- [ ] 每条产线的原料有稳定来源（不依赖手动补料）
- [ ] 中间产物有去向（不堆积卡线）
- [ ] 断电/堵料有冗余路径

## 案例参考：武陵地区

武陵的工业体系（以**息壤材料**为核心）是学习自动化设计的最佳教材：

- 供电设备**自动连接**，不需要手动拉线
- 仓库存取线灵活布局
- 引入**玩家共享设备机制**：滑索架、便捷存取站构建互助式探索生态

## 新手常见布局错误

1. **产线铺满才发现电力不够** → 永远先扩电再扩线
2. **仓库离产线太远** → 物流时间吞掉效率
3. **所有产线挤在一个区** → 一处故障全图瘫痪
4. **忽视共享设备** → 重复建设浪费资源
5. **只顾当前配方** → 预留改造空间，版本迭代会换配方
