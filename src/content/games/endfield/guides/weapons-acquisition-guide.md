# 武器获取与强化指南

> 终末地的武器不是抽卡驱动而是**任务/商店驱动**——开荒期不抽武器池是最重要的纪律之一。

## 获取途径

| 途径 | 说明 |
|---|---|
| 任务赠送 | 主线与活动任务，开荒期武器主要来源 |
| 商店兑换 | 用商店货币/配额兑换（对照材料篇的兑换优先级） |
| 产线制造 | 装备原件产线的下游产品之一 |
| 武器池抽卡 | ⚠️ 前期别碰，见下 |

## 为什么前期不抽武器池

1. 抽卡资源（抽卡券/源石）优先级是 **角色池 > 武器池**——角色是机制，武器是数值
2. 任务 + 商店的武器足够推完全部主线
3. 武器池保底资源沉没后不可回收，挤压限定角色池的预算（对照抽卡纪律篇）

## 强化与角色匹配原则

武器培养**跟随角色优先级**（对照养成优先级篇）：

- 核心输出 → 输出向武器：对应伤害属性加成、技能倍率提升
- 辅助 → 功能向武器：减抗、增伤效果
- 奶妈 → 生存向武器：治疗量、技能范围

非核心角色的武器**不预支强化资源**——升级材料不可回收，过渡武器的投入在替换时全部作废。

## 里程碑建议

- 开荒期：任务武器拉到"够用"（能打过当前主线即可）
- 资源副本解锁后：定向刷武器强化材料
- 核心输出毕业后：再考虑商店高阶武器兑换
