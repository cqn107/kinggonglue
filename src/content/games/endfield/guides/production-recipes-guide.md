# 产线配方速查

> 汇总当前版本主流高效率产线的**思路与配置要点**。蓝图码来自社区共享，导入后请自行核对产量数值（标 {{待验证}}）。

## 产线优先级（先造谁）

按养成刚需排序，优先保障这三条核心产线，再考虑贸易向产品：

1. **装备原件**——角色养成硬通货
2. **药品**——高难战斗消耗品
3. **基础零件**（钢材/晶体外壳/紫金零件）——上层配方的前置

## 关键配方链速查

| 产品 | 链路 | 要点 |
|---|---|---|
| 息壤 | 锦草 + 砂叶 → 采种机 → 加工 | 双植物自循环，各 20 株，记得连水管 |
| 息壤装备原件 | 息壤 → 精炼 → 配件机 | 有总线/无总线两版布局 |
| 芽针针剂 | 芽针 ×10 自循环 → 针剂 | 最简单的自循环线之一 |
| 晶体外壳 | 紫晶矿 → 精炼炉 → 紫晶纤维 → 配件机 | 分段加工典型 |
| 工业爆炸品 | 紫金零件 + 酮化灌木粉末 → 封装机 | 两条前置产线汇流 |
| 电池（低容/高容） | 源石粉 + 铁零件 → 封装机 | SC 电池 3 输入源石粉 + 2 输入铁零件可让封装机零停机 |

## 自循环植物农场（一劳永逸）

植物类资源的标准解法是**种植机回环**：

1. 采种机输出的种子分两路：一路回接种植机（补种），一路直通协议核心（收货）
2. 两个种植机：一个循环供给采种机，一个输出成品

## 布局通用原则

- **总线系统**：解锁后用总线整合多条产线，分流器做精准配送；总线版布局占地小、扩展容易
- **零停机检验**：观察封装机/配件机是否间歇停机——有等待就是上游配比错了
- **角落位**：部分高密度布局（如胶囊类产品）必须放在基地角落才能对齐接口
- 产线发展节点随主线第 3 章解锁；工业点数靠地图上的协议采录桩获取
