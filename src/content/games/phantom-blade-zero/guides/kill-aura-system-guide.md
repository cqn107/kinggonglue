# 杀气系统详解

> 影之刃零的上限不在手速，在**杀气管理**。看懂这一条黄条，战斗就通了。

## 杀气槽是什么

血条下的黄条，同时承担三重作用：

1. **精力**：重攻击、架势状态、普通格挡白光攻击都消耗它
2. **技能资源**：杀气达到阈值可释放处决、武器必杀、影之武装远程技能
3. **破防判定**：打空 = 自己破防——战斗的关键就是让对手先空

## 核心循环：白光 → 鬼步 → 绝技

这是本作最重要的资源循环：

1. **完美格挡白光攻击** → 大幅削减敌方杀气 + **瞬间回满自身杀气**
2. 回满的瞬间触发**鬼步**：自动绕到敌人背后
3. 鬼步给当前武器**充能** → 充满释放**绝技**：高伤害、强削刃、自带霸体

一句话：**白光是弹药，鬼步是装填，绝技是开火。** 拆解 Boss 前先把这条循环练成本能。

## 架势状态的使用时机

架势状态自动格挡大多数攻击（持续消耗杀气），适合：

- 混战中被多人围攻时**稳住局面、寻找出手窗口**
- 不熟悉的新敌人招式试探期

不适合：面对红光攻击（无法防御，必须精准闪避）——架势开着也一样掉血。

## 实战纪律

- **切武器回杀气**：战斗中切换主武器立即回满杀气，是延长连段的核心手段——两把主武器不是备胎，是连招的一部分
- 杀气低于 30% 时避免主动进攻，转防御循环
- 敌人的红光/白光有固定前摇（对照各 Boss 专篇的信号表）
