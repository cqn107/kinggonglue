# PC 优化与设置速查

> 本作 PC 端针对键鼠优化、支持 DLSS/FSR 与光追。遇到问题的按本速查逐项排查。

## 画质与性能

- **支持 DLSS 与 FSR 超分辨率**：中端显卡建议优先开，帧数收益远大于画质损失
- 光线追踪：高配可选，卡顿首选关闭项
- 高负载战斗掉帧：更新显卡驱动 → 关闭后台程序 → 限制后台浏览器硬件加速

## 常见问题速查

| 问题 | 解法 |
|---|---|
| 启动报错/激活文件异常 | 关闭 360/电脑管家等杀毒软件；Win10+ 关闭安全中心实时保护（误杀激活文件） |
| 安装路径报错 | 安装目录用**纯英文无空格**路径（如 `D:\Game\PBZ`），不要含中文 |
| 2K/4K 分辨率画面异常 | 兼容性设置勾选"替代高 DPI 缩放行为"，或改窗口化 |
| 后台程序冲突 | 关闭常驻的杀软/管家类后台进程后重启游戏 |
| 卡顿掉帧崩溃 | 先核对配置 → 更新驱动 → 释放后台内存/CPU → 开超分辨率 |

{{待验证：各档位显卡的推荐画质预设与帧数表现——发售初期社区数据补充后更新}}

## 手柄与键位

- PS5 端适配 DualSense 触觉反馈；PC 端键鼠与手柄双支持
- 动作游戏建议手柄玩家保留**默认键位**先适应，弹反/闪避的肌肉记忆成本最低
- 改键原则：完美格挡与闪避必须放在**独立、易按**的键位——这两个键的使用频率最高

## 音画体验

- 支持杜比全景声：本作的**出招音效是白光/红光判断的辅助信号**，别开静音玩
- 悬念场景依赖音频提示（潜行篇），建议戴耳机
