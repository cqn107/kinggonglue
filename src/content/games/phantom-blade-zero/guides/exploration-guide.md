# 影境探索与奇遇指南

> 官方把影境叫做"一纸水墨上的功夫箱庭"：手工打造的关卡、精心设计的每一条路径。本篇讲怎么把这张地图走干净。

## 世界结构

- **八幅纯手绘水墨地图无缝衔接**，以庞镇为中心区域向四周延伸
- 场景类型：被匪徒盘踞的山谷、悬挂人偶的废弃仓库、蒸汽钢铁高塔、需特殊快船渡过的广阔湖面等
- **半开放组织**：不是罐头开放世界——每条岔路都是手工放置的内容

## 奇遇系统

"江湖处处充满奇遇"是本作探索的核心卖点：

- 有的奇遇导向**一条跌宕起伏的长段支线**（结局级内容，见结局篇）
- 有的只是拼出更大秘密的小片拼图——别跳过看似琐碎的对话
- 触发逻辑偏向**主动接近与交互**：看到非敌对 NPC、特殊场景物件就上去看

## 探索收益优先级

| 目标 | 价值 | 备注 |
|---|---|---|
| 隐藏心法 | ★★★★★ | 战斗构筑的关键拼图 |
| 限定武器 | ★★★★★ | 部分武器只能探索获得 |
| 长支线入口 | ★★★★ | 剧情与结局相关 |
| 支线 Boss | ★★★ | 掉落 + 挑战乐趣 |
| 宝箱/收集品 | ★★ | 顺手拿，别为全收集打乱主线节奏 |

## 探索节奏建议

1. **区域主线 Boss 前留探索时间**：击败后小怪永久不刷新，战利品收集会变无聊
2. **存档点密集**，死亡惩罚友好——大胆往岔路里走
3. 阴雨与夜景变化会改变场景氛围（与部分隐藏内容相关{{待验证}}），同一区域不同时段值得重访
4. 潜行视角探图两用：清点位的动线与暗杀动线高度重合（见潜行篇）
