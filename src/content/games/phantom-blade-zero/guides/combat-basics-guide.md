# 战斗基础与新手练习路线

> 本作上手门槛不高——机制环环相扣，但**练习顺序**对了可以少走很多弯路。

## 基础操作五件套

| 操作 | 说明 | 优先掌握度 |
|---|---|---|
| 轻重攻击衔接 | 连招基本盘 | ★★★★★ |
| 格挡 / 完美格挡（白光） | 大幅削敌杀气 + 自身瞬间回满 | ★★★★★ |
| 闪避 / 精准闪避（红光） | 红光不可防，只能闪 | ★★★★★ |
| 鬼步 | 完美格挡触发，自动绕背 | ★★★★ |
| 处决 / 绝技 | 杀气/充能满后释放，高伤削刃霸体 | ★★★ |

机制原理见杀气系统详解篇——本篇只管**怎么练**。

## 第一小时练习路线

### 0–15 分钟：庞镇杂兵场

- 目标只有一个：**白光完美格挡的成功率过五成**
- 方法：找落单杂兵，故意不进攻，纯弹反——把"看信号→按格挡"练成反射
- 顺带体会：弹反成功 → 杀气回满 → 鬼步绕背的完整链条

### 15–30 分钟：轻攻击压制 + 切武器

- 轻攻击连段中**切第二把主武器**：立刻回满杀气，无缝接续
- 练"两把武器是一套连招"的意识（对照武器篇的配对思路）

### 30–45 分钟：红光应对

- 红光攻击不可防——练**识别前摇 → 精准闪避 → 反击**三拍
- 红光/白光的混合节奏是本作战斗的真正考点

### 45–60 分钟：杀气纪律实战

- 定规矩：杀气低于 30% 不主动进攻
- 练"防御循环回资源 → 窗口期爆发"的节奏，而不是无脑对拼

## 常见新手错误

1. ❌ 只进攻不弹反——杀气是双方共享的经济，你比敌人先空就破防
2. ❌ 红光硬吃——架势状态也挡不住红光
3. ❌ 两把主武器带同类型——切武器回杀气的机制要求**互补**，不是备份
4. ❌ 死磕 Boss 超 5 次——先看本站 Boss 拆解系列（万钧/红衣/大师兄），再不行看难度选择篇
