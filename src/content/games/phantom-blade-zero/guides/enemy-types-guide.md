# 敌人类型与应对手册

> 本作的武器系统天生就是**为不同敌人准备的钥匙**——对照下表换武器，比硬拼省一半力气。

## 常规敌人类型速查

| 敌人类型 | 识别特征 | 推荐应对 |
|---|---|---|
| **巨盾兵** | 持巨盾、格挡常态 | 铁拳/巨锤类武器**破防**——盾在人在，盾破必倒 |
| **远程火器阵** | 排枪/弓弩齐射 | **虎炮**对轰打散阵型；或潜行逐个点名 |
| **群体杂兵** | 数量多、行动快 | **喷火类**（烈焰狮头）范围压制 |
| **危险目标（炸药桶等）** | 场景内红色目标 | 远程武器**提前引爆**，借力打力 |
| **空中/丝线系** | 荡索、滞空 | **灵蛇软剑**以柔克刚，可切断空中丝线 |

## 精英/特殊敌人

- **异化怪面**：人体改造产物，杀气/硬直机制与常人不同{{待验证}}——优先观察其红光/白光信号再近身（对照杀气篇）
- **江湖高手**：人形精英，招式成体系，按 Boss 战的出招前摇记录法拆解（对照 Boss 通用思路篇）

## 三条通用纪律

1. **进战前换装**：看到什么敌人类型，开场前就把克制武器放进两主武器 + 两影之武装的四个槽位——本作切武器无硬直代价，但槽位有限
2. **副武器是战术钥匙**：对群、对盾、对远程各有专属解，弹药留给"正确的问题"（对照影之武装篇）
3. **打不过就潜行**：多数据点类遭遇都可以绕后暗杀削弱开局（对照潜行篇）
