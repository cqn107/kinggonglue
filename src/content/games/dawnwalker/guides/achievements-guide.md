# 全成就规划

> 成就的大头是**结局类**（7 结局）与支线完成类。核心思路：一周目拿"流程成就"，用结局前存档批量收结局，二周目收尾。

## 一周目可同步解锁

按主线自然推进即可拿到，无需刻意操作：

- 区域推进类（序章 / 安布鲁斯 / 巴基尔 / 赞西相关流程成就）
- 战斗机制类（完美格挡、处决等教学型成就——见到机制就刻意完成一次，不留尾巴）
- 收集类（边推边收，对照收集点位）

## 结局类成就的存档策略

7 结局对应不同选择链（详见本站结局篇），推荐流程：

1. **终章前打一个手动存档**（确认该存档仍可回溯结局分歧点）
2. 结局 A → 读档 → 调整关键选择 → 结局 B，依此类推
3. 早期结局（2 个）若已错过，记入二周目清单——早期结局可能需要新开档

⚠️ 读档前先确认成就进度已上传（离线成就有同步延迟）。

## 多周目/二周目清单

- [ ] 早期结局 ×2（对应开局关键选择）
- [ ] 坏结局（叛徒线，恶名 9 级相关——见恶名篇）
- [ ] 漏掉的长支线（拉克拉 / 克雷克任务链等）
- [ ] 收集类补漏

## 时间预算

- 一周目（含同步成就）：约 40–60 小时（含探索）
- 结局批量收集：2–4 小时（若存档点选得好）
- 二周目收尾：只跑差异路线，10–15 小时
