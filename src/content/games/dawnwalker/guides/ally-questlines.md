# 盟友任务线详解：拉克拉与克雷克

> 两条支线互相独立，是「弑亲者」「拥立大公者」结局的**硬性前置**——中途断掉无法解锁。任务链译名各来源有差异，以游戏内为准（标注待验证）。

## 发育期就该启动

推荐第 4–12 天（发育期）启动两条线，白天做城镇事务、夜晚推进盟友线（两条线的多数任务都限夜晚）。

## 拉克拉（吸血鬼线）

| 顺序 | 任务 | 备注 |
|---|---|---|
| 1 | 如此挚友 | 开启任务，{{待验证：夜晚在斯瓦特劳东北侧城墙附近触发}} |
| 2 | 山之歌 | |
| 3 | 蜂群搜寻 | |
| 4 | 腐朽根源 | |
| 5 | 恐怖之夜 | 可选——完成后解锁成就「祸不单行」（感情线） |
| 6 | **午夜清算** | 最终任务，对话选合作 → 联手决战 → 弑亲者结局 |

**线内要点**：
- 全程限夜晚的任务提前规划路线
- 最终决战时拉克拉作为盟友参战
- 决战前布伦西斯也会抛出交易——想保住此结局**不要接受**

**交叉提醒**：叛徒（背叛）结局需要完成《煽动者》《林中暗影》《忠诚何在》三任务获得解放者藏身点准入——所以就算想走背叛线，这条线的前三步也值得做。

## 双线并行节奏建议

1. 第 4–12 天：两条线同步推进到中段
2. 第 13–22 天：推三大博雅尔期间顺路完成剩余任务
3. 第 23–29 天：确认两线全部完成 → 最终任务前手动存档 → 一周目即可依次触发联手结局与独自决战结局
