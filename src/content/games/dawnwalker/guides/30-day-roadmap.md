# 30 天开荒规划

> 核心原则：倒计时只在**完成主线节点、提交任务、神社等待**时推进——自由跑图、搜刮、清野怪完全不消耗天数。**前 20 天发育，最后 7–10 天集中推主线。**

> 🧰 **配套互动工具**：[30 天规划追踪器](/tools/dawnwalker-30day-planner) —— 按阶段勾选关键目标，进度本地保存；结局选择配合[结局路线规划器](/tools/dawnwalker-endings)。

## 第 1–3 天：序章 + 开图

- [ ] 序章：**救活艾斯梅**（药剂必须正确，否则锁大量结局）
- [ ] 蓝色时钟标记的支线入夜永久消失，优先做完
- [ ] 白天：清理周边强盗营地，解锁神龛传送点，标记资源点
- [ ] 夜晚：直奔断桥偷**杜兰德尔**（暗影步潜入，拿完就走）
- [ ] 认识橙色沙漏图标：出现即代表该操作消耗时间，**动手前先手动存档**

## 第 4–12 天：发育期

- [ ] 白天：往返斯瓦特劳城采购物资、接城镇支线
- [ ] 夜晚：清精英营地，收集剑术/巫术手册
- [ ] 开启两大盟友支线：**拉克拉**（吸血鬼线）、**克雷克**（解放者线）——想要对应结局必须完整做完任务链，缺一不可
- [ ] 启动支线「僧侣与圣徒」，集 3 块碎片铸**圣米哈伊大剑**
- [ ] 恶名管理：杀人/偷袭全放野外夜晚，城镇内不动手

## 第 13–22 天：战力成型，推三大博雅尔

- [ ] 推荐顺序：**安布鲁斯 → 巴基尔 → 克桑特**
- [ ] 每击败一个解锁大片新区域与高阶装备
- [ ] 击杀会缓慢涨恶名：打完野外立刻离开，不逗留城内
- [ ] 期间继续补手册、导师解锁与装备强化

## 第 23–29 天：结局前置 + 存档备份

- [ ] 三博雅尔击败后回城触发最终主线
- [ ] **关键操作：进入最终任务前手动单独存档**——读档即可一周目解锁全部 7 结局，无需二周目
- [ ] 确认拉克拉/克雷克支线是否做完（联手结局的硬性前置）

## 第 30 天：决战日

- 进攻格赖夫贝格城堡，按对话选择走向不同结局（见《全结局攻略》）

## 时间管理铁律

1. 橙色沙漏 = 消耗时间 → 先存档
2. 不要频繁用神社"等待"跳时间（除非刻意刷坏结局）
3. 探索本身免费——先侦察再承诺任务
4. 只做主线宫廷活动约 10 天可通关，时间其实充裕，别被倒计时吓到
5. 不要强行做完全部支线——优先战力与盟友线
