# 全结局攻略：7 个结局达成条件

> 结局由**最终任务中的对话选项**决定，前期选项不影响结局判定。本文基于公开发售资料整理，选项原文待实测比对。

另：任意结局都会解锁通关奖杯「黎明行者之血」。**决斗者难度**要求完成 4 个主线正常结局并拯救拉斯莱民众。

## 全结局共同前置

1. 序章**救活母亲艾斯梅**（否则锁大量结局）
2. 30 游戏日内击败三大博雅尔：安布鲁斯、巴基尔、克桑特
3. 击败三博雅尔后恶名拉满 → 次日触发宣读恶名法令 → 收到布伦西斯谈判 → 获得最终任务「与魔鬼的交易」
4. **在最终任务处手动存档**——之后打完一个结局读档即可刷下一个

## 结局 1：万民英雄（独自决战）

- 最终任务对话选择："**够了，该结束这一切了。**" → 单人挑战布伦西斯
- 不需要任何盟友支线

**速通备选**：序章后直接潜入格赖夫贝格城堡提前终结剧情：
- 翻墙：夜晚用位面跃迁 + 暗影步攀上城墙（顶端会触发结局警告对话）
- 侧门：位于维迪拉浅滩神龛西北小径尽头，两种进入方式——
  - 与弗洛林神父合作：完成《以父之名》，选择"好吧，我们合作"（不杀他，拒绝后仍可回头）
  - 击杀拉科维察匪帮营地小头目"狂躁公爵"格奥尔格，搜取**城堡侧门钥匙**

## 结局 2：弑亲者（与拉克拉联手）

必须**完整完成**拉克拉支线任务链（全部在夜晚）：

如此挚友 → 山之歌 → 蜂群搜寻 → 腐朽根源 → 恐怖之夜（可选，解锁成就"祸不单行"）→ **午夜清算**（结局任务）

- 开启方式：{{待验证：夜晚在斯瓦特劳东北侧城墙附近触发}}
- 在"午夜清算"中与拉克拉对话选择合作路线

## 结局 3：拥立大公者（与克雷克联手）

必须**完整完成**克雷克（解放者义军）支线任务链：

煽动者 → 林中暗影 → 忠诚何在 → 暗夜猎手 → 亡者异动 → 幕后操盘手 → 遥远暗影（可选）→ 细查真相（可选，解锁成就"解放者"）→ **黎明崛起**（结局任务）

- 开启方式：{{待验证：磨坊区域触发}}
- 在"黎明崛起"中选择合作；拒绝合作会转入"杀出个黄昏"

## 结局 4：叛徒（背叛交易）

- 30 天内击败三大博雅尔，恶名达到最大值
- 最终任务对话："**我只想换回我的家人**" → 确认"**我愿意**"（第二、四处对话随意，**不要选拔剑进攻**）
- 布伦西斯要求标记解放者藏身处 → 需先完成《煽动者》《林中暗影》《忠诚何在》三任务获得准入
- 夜晚与藏身点大门交互触发
- 背叛备选：走拉克拉/克雷克线时，最终决战前接受条件同样转入此结局

## 结局 5：应得的归宿（逃离山谷）

序章后即可触发，**限夜晚**（需暗影步）：

1. 前往西侧荆棘沼泽，懦夫之路神龛以西的断桥，对面有一扇敞开的大门
2. 用位面跃迁 + 暗影步攀上峡谷岩壁，沿岩壁走到大门
3. 选择"**永远离开山谷**"

## 结局 6：永世相伴（困于梦境）

藏在克桑特宫廷活动《甜蜜之家》内（淤泥塔顶层，详见决战攻略）：

- 进入循环梦境后**无视水井**，连续完成 4 轮循环
- 第 5 轮开始时与家人对话 → 永远留在梦中
- 脱身方法见《赞西区域与最终决战攻略》

## 结局 7：时限耗尽（坏结局）

- 序章后累计超过 30 游戏日自动触发（可在神龛反复"等待"快速消耗）
- 家人被献祭的过场，主线中断，世界仍可自由探索
- 无奖杯关联

## 一周目全结局路线建议

1. 序章救活艾斯梅
2. 前 20 天：发育 + 完整做完拉克拉、克雷克两条支线（互相独立）
3. 第 13–22 天：击败三博雅尔
4. 最终任务处**手动存档**
5. 依次触发 4 个主线结局（每次读档换对话选项）
6. 早期结局 5、6 随时可补做
